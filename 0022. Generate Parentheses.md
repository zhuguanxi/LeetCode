## Problem Description
Given n pairs of parentheses, write a function to generate all combinations of well-formed parentheses.

 

Example 1:

Input: n = 3
Output: ["((()))","(()())","(())()","()(())","()()()"]
Example 2:

Input: n = 1
Output: ["()"]

### WAY 1:
* 組合回朔，不管嘗試左右括號都要退回來
```
class Solution {
public:
    void dfs(vector<string>& ans, string& path, int n, int left, int right)
    {
        if (right > left) return;
        if (left > n) return;

        if (path.size() == (2 * n)) 
        {
            ans.push_back(path);
            return;
        }
        
        path.push_back(')');
        dfs(ans, path, n, left, right+1);
        path.pop_back();

        path.push_back('(');
        dfs(ans, path, n, left+1, right);
        path.pop_back();
    }
    vector<string> generateParenthesis(int n) {
        vector<string> ans;
        string path = "(";

        dfs(ans, path, n, 1, 0);

        return ans;
    }
};
```
* n：poles 的長度 (1 <= piles.length <= 100)
* Time Complexity $O(n^2)$
* Space Complexity $O(n^2)$
