## Problem Description
You are given an integer n. There is an undirected graph with n vertices, numbered from 0 to n - 1. You are given a 2D integer array edges where edges[i] = [ai, bi] denotes that there exists an undirected edge connecting vertices ai and bi.

Return the number of complete connected components of the graph.

A connected component is a subgraph of a graph in which there exists a path between any two vertices, and no vertex of the subgraph shares an edge with a vertex outside of the subgraph.

A connected component is said to be complete if there exists an edge between every pair of its vertices.

### WAY 1:
* 先建 graph
* 執行 dfs 計算點跟邊關係來決定是否為 complete connected components
```
class Solution {
public:
    void dfs(int u, vector<bool>& visited, vector<vector<int>>& graph, int& edge, int& node)
    {
        visited[u] = true;
        
        node++;
        edge += graph[u].size();

        for (int i=0; i<graph[u].size(); i++)
        {
            int v = graph[u][i];
            if (visited[v] == false)
                dfs(v, visited, graph, edge, node);
        }
    }

    int countCompleteComponents(int n, vector<vector<int>>& edges) {
        int ans = 0;

        vector<bool> visited(n, false);
        vector<vector<int>> graph(n);

        for (auto edge : edges)
        {
            int v = edge[0];
            int u = edge[1];

            graph[u].push_back(v);
            graph[v].push_back(u);
        }

        for (int i=0; i<n; i++)
        {
            if (visited[i] == false)
            {
                int edge = 0;
                int node = 0;

                dfs(i, visited, graph, edge, node);
                
                edge /= 2;
                
                if (edge == node * (node - 1) / 2)
                    ans++;
            }
        }

        return ans;
    }
};
```
* V：node 的個數 (1 <= V <= 50)
* E：edges 的長度 (0 <= edges.length <= V * (V - 1) / 2)
* Time Complexity $O(V + E)$
* Space Complexity $O(V + E)$
