## Problem Description
You are given a positive integer n.

Return the maximum product of any two digits in n.

Note: You may use the same digit twice if it appears more than once in n.

### WAY 1:
```
class Solution {
public:
    int maxProduct(int n) {
        int max_num = -1;
        int sec_num = -1;
        while (n != 0)
        {
            int rem = n % 10;
            n = n / 10;

            if (sec_num > rem)
                continue;
            else if (rem >= max_num)
            {
                sec_num = max_num;
                max_num = rem;
            }
            else if (rem < max_num && sec_num < rem)
                sec_num = rem;
        }

        return max_num * sec_num;
    }
};
```
* n：10 <= n <= 10e9
* Time Complexity $O(n)$
* Space Complexity $O(1)$
