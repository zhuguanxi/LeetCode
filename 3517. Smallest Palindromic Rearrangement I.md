## Problem Description
You are given a palindromic string s.

Return the lexicographically smallest palindromic permutation of s.

### WAY 1:
* 用 counting sort 可以更快
```
class Solution {
public:
    string smallestPalindrome(string s) {
        int n = s.size();

        string half_s = "";

        for (int i=0; i<n/2; i++)
            half_s+=s[i];
        sort(half_s.begin(), half_s.end());

        string ans = half_s;
        if (n%2 != 0) ans+= s[n/2];

        for (int i=half_s.size()-1; i>=0; i--)
            ans+=half_s[i];

        return ans; 
    }
};
```
* n：字串 s 的長度 (1 <= s.length <= 10e5)
* Time Complexity $O(nlogn)$
* Space Complexity $O(n)$
