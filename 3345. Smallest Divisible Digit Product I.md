## Problem Description
You are given two integers n and t. Return the smallest number greater than or equal to n such that the product of its digits is divisible by t.

### WAY 1:
```
class Solution {
public:
    int smallestNumber(int n, int t) {
        
        while (true)
        {
            int tmp = n;
            int product = 1;
            while (tmp > 0)
            {
                int c = tmp % 10;
                product *= c;
                tmp /= 10;
            }
            if (product % t == 0)
                return n;
            else
                n++;
        }
        
        return n;
    }
};
```
* 1 <= n <= 100
* Time Complexity $O(n)$
* Space Complexity $O(1)$
