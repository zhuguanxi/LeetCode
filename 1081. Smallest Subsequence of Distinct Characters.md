## Problem Description
Given a string s, return the lexicographically smallest subsequence of s that contains all the distinct characters of s exactly once.

### WAY 1:
* 使用 monotonic stack 概念，並且搭配 cnt_map 和 Visited 來判斷是否還剩餘以及是否已辦訪過(先拜訪的一定比較大) 
```
class Solution {
public:
    string smallestSubsequence(string s) {
        vector<int> cnt_map(26, 0);
        vector<bool> Visited(26, false);

        for (int i=0; i<s.size(); i++)
        {
            cnt_map[s[i]-'a']++;
        }

        string ans = "";
        for (int i=0; i<s.size(); i++)
        {
            char c = s[i];
            cnt_map[c-'a']--;

            if (Visited[c-'a'])
                continue;
            else
            {
                while (!ans.empty() && c < ans.back() && cnt_map[ans.back()-'a'] > 0)
                {
                    Visited[ans.back()-'a'] = false;
                    ans.pop_back();
                }
            }
            ans.push_back(c);
            Visited[c-'a'] = true;
        }
        
            
        return ans;
    }
};
```
* n：s 的長度 (1 <= s.length <= 1000)
* Time Complexity $O(n)$
* Space Complexity $O(n)$
